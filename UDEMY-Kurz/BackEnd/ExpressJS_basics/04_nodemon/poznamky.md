**nodemon**

    => cmd tool pro automatické restartovaní nodeJS serveru při změně kódu

    -> instalovat globálně -> npm install -g nodemon
        -> lze i lokálně ale proč?
    
    -> start nodemon naz_souboru    ->    nodemon index.js 

    -> nodemon běží i když kód jako samotný ne
        -> VŽDY spustit nejdřív kód pomocí classic node (pro otestování) a pak až v nodemon
