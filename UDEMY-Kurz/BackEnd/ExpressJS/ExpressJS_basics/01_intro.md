**ExpressJS**

    => nodeJS framework pro webový backend (server-side) pro tvorbu webových apl.
        -> NPM package s hromadou metod a pluginů (essential for me...)

    -> odpovídání na requesty z FE (zpracování a odpověď)
        
        -> umí parsovat requesty (klas. http request === string)
        
        -> spojit requesty s konkrétními cestami (routy)
            -> kód co se spustí jen tehdy, když se request odkazuje na konkrétní cestu
        
        -> vytvořit finální http odpověď a odeslat ji

**Library vs Framework**

    Library => veškerou funkcionalitu aplikace si řídím sám, library je jen doplněk

    Framework => velkou část si řídí sám, já jen přidávám a upravuju
