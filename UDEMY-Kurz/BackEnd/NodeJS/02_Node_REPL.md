**Node REPL**

    => shell pro nodeJS (uvnitř běží kompletní JS)

    -> aktivuje se pomocí commandu node v CMD nebo při spuštění JS souboru pomocí node

    -> zde NEEXISTUJE DOM !!!!!!

    -> místo global scope "window" je zde "global" 
        -> obsahuje veškerou JS funkcionalitu + další věci co v browseru nejsou
            -> interakce se soubory a OS, apod.
