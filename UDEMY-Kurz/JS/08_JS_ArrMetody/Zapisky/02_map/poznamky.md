**Map**
    = vytvoří spec. array s výsledky pro zpětné (callback) volání
        -> vznikne nový array s upravenými hodnotami

    - array metoda, přidáme za původní array pomocí dot notation
    
    - map postupně vezme každou hodnotu > prožene ji funkcí v () > upravenou hodnotu zapíše do nového arraye (musí být uvedena v return !!!)

    - u arrayů s objekty musím podrobnějí specifikovat key-val

    - lze vyfiltrovat jen to co chci měnit, ale commonly se používá pro měnění/úpravu všech hodnot
