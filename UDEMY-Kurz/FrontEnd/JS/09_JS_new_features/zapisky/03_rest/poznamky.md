 **arguments object**
    = objekt podobný arrayi
      -> má property udávající délku
      -> nemá array metody

    - obsahuje všechny hodnoty passnuté do fce.
    - NEFUNGUJE v arrow funkcích!!!!!!!


**rest**
  = když chci do funkce passnout neurčitý počet argumentů
    -> veškeré argumenty se vloží do 1 arraye, který se použije dál ve fci. pod názvem passované rest prop.

  -> syntax stejný jako u spread

  - samostatné passované argumenty mohou být JEN před spread propem. za ním NE!
