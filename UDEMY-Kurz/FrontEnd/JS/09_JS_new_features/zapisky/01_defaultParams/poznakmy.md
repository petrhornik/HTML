**default params**
  = hodnotám passovaným do fce. se dají přednastavit hodnoty

    -> pokud se při volání fce. některá z požadovaných hodnot nepassne tak se místo undefined použíje ona default

    -> vyvarování se chyb při undefined hodnotě (nevznikne)

  1) starý způsob
    = pomocí if statementu

  2) nový způsob
    = přímo u proměnné pro passovanou hodnnotu v () u definování fce.
