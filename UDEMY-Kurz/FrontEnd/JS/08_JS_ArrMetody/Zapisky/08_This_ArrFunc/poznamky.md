**This + arrow fce.**
  = this v arrow fci se vždy bude odkazovat na scope ve které je vytvořen
    -> v přikladu se odkazuje na global scope
      -> objekt je přiřazen do GLOBÁLNÍ proměnné
    -> this v arr fcích se hodí např. u metod pro window objekt (např.: setTimeout)


tip -> normální fce nebere ohled na to kde byla vytvořena, ale jak je spuštěna

tip#2 => this uvnitř arrow a klas. fce funguje jinak
