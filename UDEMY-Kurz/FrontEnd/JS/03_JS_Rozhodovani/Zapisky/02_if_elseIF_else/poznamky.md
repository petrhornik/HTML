**if**
    = provede se část kódu obsažená v if pokud se splněna podmínka obsažená v () na true
    syntax: if (podminka){kod};
    - viz.: 020 > app.js

**Else if**
    = provede se jen pokud podmínka na kterou navazuje je false a jeho podmínka vyjde true
    - viz.: 021 > app.js

**else**
    = provede se pokud žádná z předchozích if nebo else_if podmínek není splněna(true)
    -> provede se vždy když nic jiného není platné
    - uvádí se vždy na konec celého rozhodování
    - viz.: 022 > app.js

important -> vždy musíme začínat if
        -> else if ani else nebude jinak fungovat!!!
