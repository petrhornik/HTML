**AJAX** -> asynchronní JS a XML

    => způsob dělání requestů přímo z kódu
    -> dělání requestů pro načtení informací či odeslání pro uložení něčeho atd. na pozadí (většinhou dynamicky)

    -> jednotlivé requesty a odpovědi lze sledovat v network tabu v dev tools

    -> requesty v 99% vrací JSON. který se musí PARSEnout (more on that later)

    - typy:
      - XMLHTTP
      - FETCH
      - AXIOS
