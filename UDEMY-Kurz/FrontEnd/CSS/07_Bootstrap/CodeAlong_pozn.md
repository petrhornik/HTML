**container-fluid**
    = druh containeru kde kontent je roztažen přes celý width okna/vyhrazeného prostoru
    - normální container má vždy určitý margin od left a right okraje okna

**responziv obrázky by Bootstrap**
    = obrázku připo přidáme class img-fluid
    - tip - chová se podobně jako max-width: 100%;
    - responzivní obrázky made EZ :DD

**display property**
    = pro druh zobrazení kontentu
    - syntax: d-{breakpoint}-{typ}
    - breakpoint je optional
    - typ: none, flex, block, inline, ...

**Přerovnání položek v row (order)**
    = přerovnání položek v row oproti defaultnímu řazení
    - syntax: order-{pořadí} -> např.: order-1 (prvek bude 1.)
