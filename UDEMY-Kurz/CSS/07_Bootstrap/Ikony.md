**Ikony ala bootstrap**
    = bootstrap nám zdarma poskytuje ikony pro použití
    - URL odkaz: https://icons.getbootstrap.com/icons

    - ikony si buď stáhneme jako npm package nebo si u každé ikony lze zkopirovat odkaz <svg>
        -> škálovatelné :D, lze opět cutomizovat :DD
        -> chovají se jako obyčejný text (lze brát jako font)

    - pro škálovatelnost ikony si můžu nastavit height a width vlastnosti na em jednotky (např.: 1em)

**input group**
    = pro přidávání dalších prvků okolo nějakého inputu
    - často se využívají ikony
    
   1) setup
        - vše se uzavře do divu s class input-group
        - vytvoříme si nějaký druh inputu
        - teď můžeme přidávat prvky -> každý ve vlastním divu s dannou class
        
   2) jak pozicovat
        
        např.: input-group-prepend -> prvek se pozicuje před text input
                - může obsahovat např. ikonu

                další pozicování viz.: https://getbootstrap.com/docs/5.3/forms/input-group/
